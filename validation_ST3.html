Feedback Page — Validation Report

Initial validation — errors found

When I first ran feedback.html through the W3C validator I got two errors. The first was that the <style> element is not allowed as a child of <main> — I had placed my page-specific CSS block inside the <main> tag rather than in the <head>. The second error was a heading hierarchy issue: the review card headings were marked as <h4> which jumped from the section <h2>, skipping <h3> entirely.

After fixes — no errors

I fixed both issues by moving the <style> block into the <head> section and changing the review card headings from <h4> to <h3>. After these changes the validator returned no errors.
